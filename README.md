
# TecnoPuntoInventario

## 1. Descripción del proyecto
TecnoPuntoInventario es un sistema de consola desarrollado en C# que permite registrar y controlar productos de una tienda de tecnología.

## 2. Objetivo
Desarrollar un programa que permita almacenar información de productos, validar sus datos y calcular el valor total de las existencias.

## 3. Tecnologías utilizadas
- Lenguaje de programación: C#
- Plataforma: .NET
- Entorno de desarrollo: Visual Studio

## 4. Características principales
- Registro de productos.
- Almacenamiento de código y nombre.
- Registro del precio unitario.
- Registro de la cantidad disponible.
- Cálculo del valor total.
- Visualización de la información de cada producto.

## 5. Validaciones
El sistema comprueba que:
- El código no esté vacío.
- El nombre no esté vacío.
- El precio sea mayor que cero.
- La cantidad no sea negativa.
- Los datos numéricos tengan un formato válido.

## 6. Fórmula utilizada
Valor total = Precio unitario × Cantidad.

## 7. Productos utilizados en las pruebas
- Monitor: RD$12,500.00
- Impresora: RD$8,500.00
- Memoria USB: RD$750.00

## 8. Ejecución del programa
1. Abrir el proyecto en Visual Studio.
2. Ejecutar el programa.
3. Introducir los datos solicitados.
4. Consultar la información registrada en la consola.

## 9. Conclusión
Este proyecto permite aplicar conceptos de programación orientada a objetos, clases, propiedades, constructores, métodos, encapsulamiento y validación de datos.
